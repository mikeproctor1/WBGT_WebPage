WBGT is estimated from air temperature, relative humidity, UV index and cloud cover using the shade approximation WBGT = 0.567·T + 0.393·e + 3.94 (e = vapour pressure), with a solar loading term added for direct sun exposure. This is not a black-globe thermometer reading — treat it as a planning estimate, not an official measurement. Data: Open-Meteo.
